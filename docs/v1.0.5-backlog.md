# Acts 1.0.5 backlog

Version **1.0.4** is skipped. Next store build targets **1.0.5** (after 1.0.3 in review / on sale).

Deferred polish and follow-ups from the 1.0.3 cycle. None of these block the current App Store
review; they ship in the 1.0.5 build.

## Security / privacy

- [x] **Login email exposure.** Username/phone login uses callable `resolveLoginIdentifier`
      (rate-limited); `usernames` / `phoneLoginLookup` reads require auth. Deploy:
      `firebase deploy --only functions,firestore:rules`
- [x] **`registeredContactKeys` PII.** Client reads blocked; rate-limited `lookupContactKeys` /
      `checkContactKeyTaken` callables return minimal fields. Keys store `uid` only. Users can opt
      out via Settings → Privacy → Contact discovery. Deploy: `firebase deploy --only functions,firestore:rules`
- [ ] **Session replay decision.** Replay + `sendDefaultPii` were removed from Sentry to match
      the privacy policy. If replay is wanted, disclose it in the App Store privacy labels and
      re-enable it in `shared/services/sentry.ts`.
- [x] **Move `EXPO_PUBLIC_SENTRY_DSN` into EAS** — hardcoded fallback removed from
      `shared/services/sentry.ts`; set DSN in Expo Production (see `docs/eas-production-checklist.md`,
      `docs/release-1.0.5.md`).

## UI polish

- [x] **Midnight Studio cosmetic-card chips.** Themed task rows use `readableChipColors()` for
      cadence/difficulty/category and memory pills. (`features/tasks/components/TaskRow.tsx`)
- [x] **Deed card tints in dark themes.** Pastel tints return on deed cards with text derived from
      the tint background via `resolveDeedPostCardPresentation()`. (`deedPostDisplay.ts`, deed feed)

## Features

- [x] **Seasonal challenge photos.** Optional photo on challenge log (library/camera on native);
      stored at `season_challenge_photos/{uid}/…` with URLs on `seasonProgress`. (`challenges.tsx`,
      `storageUploads.ts`, `storage.rules`)
- [x] **Invite landing page.** `legal/join.html` reads `?invitedBy=`, deep-links `acts://join`, and
      links to the App Store. Deploy with `firebase deploy --only hosting`. Default share URL uses
      `{LEGAL_BASE}/join` (`shared/config/appInvite.ts`).
