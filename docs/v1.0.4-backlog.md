# Acts 1.0.4 backlog

Deferred polish and follow-ups captured during the 1.0.3 submission. None of these
block the current App Store review; they are queued for the next build.

## Security / privacy

- [ ] **Login email exposure.** `usernames` and `phoneLoginLookup` are publicly readable
      (`get: if true`) and contain `authEmail`, which allows email harvesting by guessing
      usernames or phone numbers. Replace the public doc reads in the username/phone login
      flow with a rate-limited callable Cloud Function that resolves an identifier to the
      auth email server-side. (`firestore.rules`, `features/auth/services/resolveLoginIdentifier.ts`)
- [ ] **`registeredContactKeys` PII.** Readable by any authed user; exposes name / username /
      uid keyed by a contact hash. Acceptable for contact matching, but revisit if abuse appears.
- [ ] **Session replay decision.** Replay + `sendDefaultPii` were removed from Sentry to match
      the privacy policy. If replay is wanted, disclose it in the App Store privacy labels and
      re-enable it in `shared/services/sentry.ts`.
- [ ] **Move `EXPO_PUBLIC_SENTRY_DSN` into the EAS production environment** so the source-level
      fallback DSN in `shared/services/sentry.ts` can be removed.
